# Actividad 12 - Definiciones Dirigidas por la Sintaxis

Práctica de Tecnología de Compiladores.

## Contenido

### Ejercicio 1
Traducción de expresiones infijas a notación prefija.

Ejemplo:

a/2+10*c

Resultado:

+ / a 2 * 10 c

### Ejercicio 2
Cálculo del valor numérico de números reales mediante atributos.

### Ejercicio 3
Validación de árboles binarios de búsqueda utilizando atributos
mínimo, máximo y es_bst.

### Ejercicio 4
Clasificación y análisis de dependencias de una gramática atribuida.

### Ejercicio 5
Evaluación de expresiones booleanas con AND, OR e implicación.

### Ejercicio 6
Restricción semántica para aceptar cadenas con igual cantidad
de tokens A y B.

### Ejercicio 7
Inferencia de tipo y evaluación de asignaciones aritméticas.

## Tecnologías

- Python
- Visual Studio
- Git
- GitHub
